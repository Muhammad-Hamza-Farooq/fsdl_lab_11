Task 26 — Logging ML Training Metrics

Scenario

The ML team cannot track training progress across epochs.

Objective

Log training metrics professionally during model training.

Create This Script

# training_logs.py

import logging
import random
import time

logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

for epoch in range(5):

    loss = round(random.uniform(0.1,1.0), 4)
    accuracy = round(random.uniform(70,95), 2)

    logging.info(
        f\"Epoch {epoch+1} | Loss: {loss} | Accuracy: {accuracy}%\"
    )

    time.sleep(1)

Expected Output

2026-05-07 12:10:01 - INFO - Epoch 1 | Loss: 0.83 | Accuracy: 74.22%

Task 27 — Production Logging and Error Tracking

Scenario

A production inference API crashes, but engineers cannot reproduce the issue because errors are not logged properly.

Objective

Implement structured logging and exception tracking for production ML systems.

Create This Script

# production_logging.py

import logging

logging.basicConfig(
    filename='production.log',
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

def predict(x):

    try:

        result = 100 / x

        logging.info(f\"Prediction successful: {result}\")

        return result

    except Exception as e:

        logging.exception(
            f\"Prediction failed with input: {x}\"
        )

predict(10)
predict(0)
